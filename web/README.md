# Family Meals Web - 家庭餐饮管理系统 Web 前端

基于 **Next.js 15** + **Shadcn/ui** 构建的现代化家庭餐饮管理平台。

## 🎯 特性

- ✅ **现代化UI** - Shadcn/ui + Radix UI + Tailwind CSS
- ✅ **高性能** - Next.js 15 + Turbopack + React 19
- ✅ **类型安全** - TypeScript 全覆盖
- ✅ **状态管理** - TanStack Query v5 (React Query)
- ✅ **表单验证** - React Hook Form + Zod
- ✅ **主题切换** - 亮色/暗色模式支持
- ✅ **响应式设计** - 支持移动端、平板、桌面

## 🚀 快速开始

### 1. 安装依赖
```bash
cd web
npm install
```

### 2. 配置环境变量
编辑 `.env.local` 文件：
```env
NEXT_PUBLIC_API_URL=http://localhost:3000/api
```

### 3. 启动开发服务器
```bash
npm run dev
```

访问 [http://localhost:3001](http://localhost:3001)

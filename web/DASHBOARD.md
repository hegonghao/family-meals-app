# Dashboard 页面功能说明

## 🎯 功能概览

完整的Dashboard页面已经开发完成，包含以下核心功能：

### 1. 欢迎横幅 (WelcomeHeader)
- ✅ 根据时间显示不同问候语（早上好/下午好/晚上好）
- ✅ 显示随机诗词（从后端API获取）
- ✅ 精美的渐变背景设计
- ✅ 响应式图标（太阳/月亮/云朵）

### 2. 未点餐提醒横幅 (MealReminderBanner)
- ✅ 自动检测明天缺失的餐次
- ✅ 智能提示文案（支持1-3个缺失餐次）
- ✅ 橙色警告样式
- ✅ 快速跳转到点餐页面
- ✅ 已点满自动隐藏

### 3. 订单日历视图
- ✅ 周视图（显示7天）
- ✅ 上周/下周切换按钮
- ✅ 按日期分组展示
- ✅ 日期徽章颜色标识：
  - 蓝色：今天
  - 绿色：未来
  - 灰色：过去

### 4. 订单卡片 (OrderCard)
- ✅ 餐次标签（早餐/中餐/晚餐）
- ✅ 订单状态标签（待确认/已确认/已取消）
- ✅ 菜品列表展示
- ✅ 数量和特殊说明
- ✅ 备注信息
- ✅ 编辑/取消按钮（仅限本人且未过期）
- ✅ 取消时显示loading状态

### 5. 全局导航 (MainNav)
- ✅ 响应式顶部导航栏
- ✅ 主题切换（亮色/暗色/系统）
- ✅ 活动页面高亮
- ✅ 移动端适配

## 🔌 API集成

Dashboard页面使用以下API：

1. **GET /dashboard/missing-meals**
   - 获取未点餐次信息
   - 自动刷新

2. **GET /poems**
   - 获取随机诗词
   - 24小时缓存

3. **GET /orders/calendar-range?start=xxx&end=xxx**
   - 获取日历范围内的订单
   - 支持分页和筛选

4. **POST /orders/:id/cancel**
   - 取消订单
   - 自动刷新列表

## 💡 使用示例

### 查看本周订单
```
1. 进入Dashboard
2. 默认显示本周（今天+未来6天）
3. 点击"上周"/"下周"切换
```

### 取消订单
```
1. 找到要取消的订单卡片
2. 点击右上角"X"按钮
3. 等待确认Toast
4. 列表自动刷新
```

### 响应提醒
```
1. 如果明天有未点餐次
2. 顶部会显示橙色提醒横幅
3. 点击"立即点餐"跳转到菜单页
```

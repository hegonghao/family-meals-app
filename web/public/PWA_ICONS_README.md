# PWA Icons Setup

## 快速生成图标

PWA需要多种尺寸的图标。最简单的方法：

### 方法1: 在线工具（推荐）
1. 访问 https://www.pwabuilder.com/imageGenerator
2. 上传一个正方形Logo（建议512x512以上）
3. 下载生成的图标包
4. 将 `icon-192x192.png` 和 `icon-512x512.png` 放到此目录

### 方法2: 手动创建
创建两个PNG文件：
- `icon-192x192.png` (192x192像素)
- `icon-512x512.png` (512x512像素)

### 方法3: 临时占位符
开发阶段，可以暂时使用任意正方形图片重命名为对应尺寸。

## 图标设计建议

- 使用简洁的图形，避免复杂细节
- 确保在小尺寸下仍然清晰可辨
- 背景建议使用纯色或简单渐变
- 主体元素居中，四周留白10-15%
- 考虑使用品牌主色调

## 验证

配置完成后，在Chrome DevTools中：
1. Application → Manifest
2. 检查图标是否正确加载
